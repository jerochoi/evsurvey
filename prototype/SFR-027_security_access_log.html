🚨 접근 및 동시접속 이력 관리 안내

본 화면은 시스템 로그인 시점의 보안 이력을 관리하며, 특히 해외 접속 시도와 동일 계정 중복 접속에 대한 실시간 대응 결과를 기록합니다.

  • 계정 탈취 의심 사례(해외 IP, 취약 시간대 접근 등)를 시각적으로 구분하여 관리자에게 알립니다.
  • 보안 정책에 의해 차단된 '동시 접속' 사례를 분석하여 비정상적인 계정 공유 행위를 감지합니다.

[로그 분석 가이드]

🌍 해외 IP 감지 접속 IP 기반의 국가 정보(GeoIP)를 추출하여 한국 외 지역 접근을 식별합니다. 빨간색 강조 행은 보안 정책에 의해 '즉시 차단'된 사례입니다.
🌙 취약 시간대 접근 환경 설정에서 지정한 업무 외 시간(예: 00시~06시)에 발생한 로그인을 별도 표시하며, 담당자에게 알림이 발송된 내역을 확인합니다.
🚫 동시 접속 차단 하나의 ID로 두 장소에서 동시 접근 시, 설정에 따라 '기존 세션 강제 종료' 처리된 결과를 보여줍니다.

[상황별 대응 방안]

  • 해외 차단 이력 빈번 시: 해당 계정 사용자의 비밀번호 변경 권고 및 본인인증 로그(DI값) 재검토가 필요합니다.
  • 동시 접속 잦음: 계정 공유 금지 원칙을 위반한 사례일 수 있으므로 해당 담당자 교육 또는 권한 회수를 검토해야 합니다.
