  • 단순 대량 문자 발송이 아닌, 메시지 비용 최적화를 위한 스마트 라우팅 체계를 시각화하여 제공합니다.
  • 외부 전문 메시징 공급자(Service Provider)와의 API 통신 규격을 관리합니다.

[핵심 연동 메커니즘]

⚡ 스마트 라우팅 1차로 저렴한 '카카오 알림톡'을 우선 발송하고, 수신 실패 시 즉각 'SMS/LMS'로 우회 발송(Fallback)하여 전송 성공률을 극대화합니다.
🛡️ 보안 통제 정책 API Key, 인증 토큰 등 민감한 정보는 서버 내부 시스템 프로퍼티에서 관리하며, 본 화면에서는 보안을 위하 마스킹 처리되어 노출됩니다.
🖥️ 환경 설정 이력 API 엔드포인트 URL 및 서비스 공급자 버전(Bizppurio V3.0) 등의 연동 상태를 실시간으로 확인하고 모니터링할 수 있습니다.

외부 연계 API 활용 안내

무공해차 통합누리집에 연계된 외부 알림 발송 서비스(카카오톡, 문자)의 통신 전략 및 발송 규칙을 안내합니다.

현황 및 통계 알림 템플릿 관리/테스트 상세 발송 내역 조회 API 연계 안내

통신비 절감을 위한 스마트 라우팅 (Smart Routing)

무공해차 통합누리집은 사용자 편의성 향상과 통신 비용 최소화를 위해 단순 대량 문자 발송 대신 외부 전문 API(비즈뿌리오 알림톡 등)와 연동되어 있습니다.

  • 1차 발송 (우선 순위): 카카오 알림톡 전송 (건당 발송 비용이 문자 대비 저렴함)
  • 2차 발송 (우회/Fallback): 수신자가 카카오톡을 미사용하거나 알림톡을 차단하여 전송이 실패한 경우, 즉각 외부 API 서버에서 자동으로 SMS/LMS 로 전환하여 재발송합니다.
* 자동 전환 로직은 플랫폼 내부가 아닌 외부 API Gateway 단에서 일괄 처리되므로 서버 부하를 유발하지 않습니다.
