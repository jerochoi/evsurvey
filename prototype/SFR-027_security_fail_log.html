🔑 인증 실패 및 DI 로그 추적 안내

본 화면은 비밀번호 오류 또는 본인인증 실패 이력을 추적하여 무단 접근 시도를 탐지하고 동일인의 반복 공격을 식별하는 보안 화면입니다.

  • 계정 ID를 바꿔가며 시도하더라도, 본인인증(휴대폰, 인증서 등) 시 발생하는 고유값인 DI(중복가입확인정보)를 기록하여 동일인 여부를 판별합니다.
  • 로그인 실패 횟수 초과로 잠긴 계정의 해제 요청 시, 과거 이력과 대조하여 정당한 사용자인지 판단하는 근거로 활용됩니다.

[로그 상세 가이드]

📂 실패 유형 (Type) 단순 비밀번호 오입력, 5회 연속 오류에 의한 계정 잠금, 또는 본인인증 단계에서의 인증 실패 여부를 구분합니다.
🆔 DI (Duplication Info) 인증기관(NICE 등)으로부터 수신한 암호화된 개인식별값입니다. 아이디를 다르게 입력해도 실소유자가 같으면 동일한 DI값이 기록됩니다.
🛡️ 보안 추적 (IP/시간) 특정 IP 대역에서 동시 다발적으로 발생하는 인증 실패를 감지하여 '브루트 포스(Brute Force)' 공격 여부를 분석합니다.

[운영 주의사항]

  • 개인정보 보호: DI값은 시스템 내부적으로만 활용되며 외부 유출되지 않도록 엄격히 관리됩니다.
  • 잠금 해제 지원: 사용자가 본인인증 후 계정 잠금 해제를 요청할 때, 이 화면의 DI 매칭 이력을 확인하여 도용 여부를 최종 점검할 수 있습니다.
