📝 알림 템플릿 관리 및 테스트 안내

본 화면은 무공해차 통합누리집에서 발송되는 모든 메시지의 표준 문안(템플릿)을 관리하고, 실제 발송 가능 여부를 검증하는 관리 화면입니다.

  • 알림톡(카카오)의 경우 외부 공급자의 검토/승인이 완료된 문구만 실제 발송이 가능합니다.
  • 메시지 본문 내 개인화 변수(예: #{이름}, #{접수번호})의 올바른 치환 여부를 미리 확인할 수 있습니다.

[템플릿 운영 프로세스]

🧪 발송 테스트 패널 관리자 연락처로 직접 테스트 메시지를 발송하여 폰트 가독성, 링크 연결성, 변수 치환 결과 등을 최종 점검합니다.
📑 템플릿 복사/편집 기존 승인된 템플릿을 복사하여 유사한 업무(예: 보조금 배정 안내 -> 지급 안내)에 빠르게 적용할 수 있습니다.

[변수 사용 및 주의사항]

  • 치환 변수 규칙: 템플릿 내 #{variable} 형식은 시스템 내부 데이터와 자동 연동되므로 임의 삭제에 유의하십시오.
  • 실제 과금 주의: '테스트 발송' 버튼 클릭 시 실제 API 호출이 발생하며, 공급자 정책에 따라 과금될 수 있습니다.
