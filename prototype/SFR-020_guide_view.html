Central Admin Guide

기술검토 승인 결과 확인
및 통보 프로세스

본사 관리자가 통합 검토 결과를 최종 승인하고 사업자에게 통보하는 단계를 상세 안내합니다.

Phase 01

통합 승인 현황 확인

상단 메인 메뉴에서 '통합승인' 탭을 선택한 후, 전체 목록 중 본인의 담당 구역에 해당하는 승인 요청 건을 필터링하여 확인합니다.

[ 가이드 이미지 영역: 통합 승인 리스트 화면 스크린샷 ]
💡 운영 꿀팁: 배정된 요청 건이 많을 경우 '접수일자' 기준 오름차순으로 정렬하면 처리 지연 건을 우선적으로 확인할 수 있습니다.
Phase 02

검토 의견 상세 대조

외부 검토위원이 작성한 1차 의견서를 열람하여 설치 기술 기준(전기, 소방, 건축) 적합성 여부를 기재된 서류상의 데이터와 대조합니다.

[ 가이드 이미지 영역: 상세 검토서 대조 화면 ]
