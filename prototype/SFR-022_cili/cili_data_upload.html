📁 CILI 지표 데이터 관리 가이드

본 화면은 시뮬레이터 분석의 기초가 되는 원천 데이터셋을 업로드하고 관리하는 시스템 관리자용 화면입니다. 데이터의 무결성을 정밀하게 검증합니다.

[워크플로우 핵심 가이드]

📤 지표 데이터 업로드 PDI, UCI 등 개별 지표 그룹별로 가공된 최신 정보 파일을 시스템에 등록합니다.
🧪 자동 유효성 검증 업로드 즉시 파일 포맷, CRS(좌표계), 격자 매핑, 스키마 등 4가지 관점에서 자동 검증을 수행하여 오류를 사전 차단합니다.
🚀 마스터 모델 배포 업로드 완료된 각 지표 모듈들을 통합하여 시뮬레이터에 즉시 적용 가능한 '최종 master 버전'으로 빌드 및 배포합니다.

[데이터 준비 주의사항]

  • 좌표계는 반드시 EPSG:4326 (WGS84) 형식을 준수해야 지도상에 정합성을 가집니다.
  • 기존 로드된 격자(Grid) 셀 번호 컬럼이 누락되지 않았는지 확인 후 업로드하십시오.

각 지표 단위 데이터 업로드 및 유효성 검사

QGIS 등에서 가공된 특정 대/소분류(PDI, UCI 등) GeoJSON 파일을 업로드하고 좌표계(CRS) 정합성을 검증합니다.

지표 데이터 신규 업로드

데이터 유효성(Validation) 검사

1 파일 포맷 및 메타데이터 파싱
2 좌표 참조 시스템 (CRS - EPSG:4326) 무결성 검증
3 기존 전국 격자 셀(Grid)과의 병합(Join) 매핑 테스트
4 컬럼명 스키마(PDI_1 등) 호환성 판별
