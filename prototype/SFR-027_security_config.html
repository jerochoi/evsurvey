🛡️ 시스템 기본 보안 정책 (고정)

아래 정책은 시스템 전체에 기본적으로 적용되며 변경할 수 없습니다.
동시 접속 제한 기본 적용됨

동일한 계정으로 여러 IP에서 접속이 시도될 경우, 보안을 위해 기존 세션을 자동으로 방출(로그아웃)하고 이력을 기록합니다.

로그인 5회 실패 시 계정 잠금 및 알림 발송 기본 적용됨

비밀번호 입력을 연속으로 5회 실패할 경우 계정이 임시 잠금 처리되며, 계정 소유자에게 경고 알림 서비스(메일/SMS)가 자동 발송됩니다.

🛡️ 관리자 추가 접근 통제 설정

관리자 전용 해외 IP 접근 차단

플랫폼 시스템 관리자 계정(통합관리자 등)의 해외 IP 접근을 100% 차단하며 위반 내역을 기록합니다. 일반 사용자(대국민)는 포함되지 않습니다.

관리자 취약 시간대 접근 알림

시스템 사용이 적은 지정 시간대에 관리자 계정으로 로그인이 성공하거나 시도될 경우, 해당 계정 소유자의 연락처(이메일/SMS)로 즉시 알림을 발송합니다.
